# Towerborn — The Last Floor
Первый frontend-прототип Telegram Mini App.
Сейчас: главное меню, Warrior, карта, бой, intent противника, энергия, атака/защита/способности, награда, персонаж и инвентарь.
Это пока прототип без серверной авторизации, базы данных и настоящего сохранения. Эти части подключим следующим этапом.
